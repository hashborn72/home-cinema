# Домашняя медиатека

Приложение для Android TV с собственными витринами, поиском, избранным и историей просмотра.

- **Jackett** получает раздачи LostFilm, ExKinoRay и RuTor.
- **TorrServer** передаёт видео через backend плееру, используя RAM-кэш.
- **Backend** собирает каталог, подключает Anwap, хранит медиатеку и позиции просмотра. TMDB — необязательный источник постеров и описаний.
- **Android-приложение** показывает каталог; воспроизведением занимается отдельно установленный **Just Player**.

## Развёртывание

На сервере нужны Git, Docker и Docker Compose. Порт backend не должен быть занят другим сервисом.

```sh
git clone https://github.com/hashborn72/home-cinema.git
cd home-cinema
docker compose up -d
```

По умолчанию используется адрес `192.168.1.144`. Для другого адреса скопируйте `.env.example` в `.env` и измените `CINEMA_HOST` до запуска.

- Backend и страница установки: `http://192.168.1.144:8093/install`
- Jackett (`jackett:9117`) и TorrServer (`torrserver:8090`) доступны только сервисам внутри Docker Compose. Их порты на хост не публикуются.

Приложение и Just Player используют только порт backend. Видео передаётся по временной ссылке конкретного файла с поддержкой перемотки (HTTP Range), без сохранения медиапотока на диск.

Индексаторы преднастроены, но личные аккаунты LostFilm/ExKinoRay нужно перенести отдельно через каталог `private` до первого запуска. Ключ Jackett создаётся автоматически. Секреты не хранятся в Git; необязательный TMDB-токен можно положить в `private/tmdb-token` перед первым запуском.

## Телевизор

Установите подписанный APK и Just Player. APK распространяется отдельно; если положить его в `dist/home-cinema.apk`, он будет доступен на странице установки.

Откройте приложение, укажите сервер `http://192.168.1.144:8093` и нажмите «Подключить». Код и API-ключ вводить не нужно. Адрес сохраняется на телевизоре.

## Данные и обслуживание

Настройки и медиатека находятся в постоянных Docker-томах. Обычный `docker compose down` их сохраняет; **не используйте `down -v`, если данные нужны**.

```sh
docker compose ps
docker compose exec backend python manage.py backup
git pull
docker compose up -d
```

Команда backup сохраняет снимок SQLite внутри тома backend. Для защиты от потери сервера копируйте его и настройки сервисов на другое устройство отдельно.

## Проверка изменений

Для интеграционных проверок запускайте полный `compose.yaml` отдельным проектом, со своими томами и свободным `BACKEND_PORT`. Backend обращается к Jackett и TorrServer по именам сервисов внутри сети этого проекта. Старый `compose.dev.yaml` запускает только backend и больше не подходит для проверки торрентов: он рассчитывал на опубликованные порты production. Открывать их снова для разработки не нужно.

Android UI-тесты запускаются через `:app:testDebugUnitTest` и `:app:testReleaseUnitTest`. `TvLayoutTest` проверяет подписи, переключение сезонов, продолжение просмотра и фокус пульта на экране 960×540 dp; снимок отрисовки сохраняется в `app/build/reports/tv-layout`.

По умолчанию включён доверенный режим (`CINEMA_AUTH_MODE=trusted-lan`): любой, кто имеет сетевой доступ к backend, может пользоваться каталогом и менять общую медиатеку. Пароли трекеров остаются на сервере. Комплект предназначен только для доверенной домашней сети — не открывайте эти порты в интернет.
